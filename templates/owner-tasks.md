# Задачи на владельца

Здесь только то, что может сделать или решить **только владелец**: ключи, токены, входы в аккаунты, оплата, «да» на прод, решения по продукту, финальное слово по документам и по продукту в работе. Норма — `docs/ai-handoff-protocol.md`, раздел «Owner tasks».

- Работа агентов эти задачи не ждёт, кроме случаев из списка блокирующего (там же).
- **Одна задача = одно действие** (один секрет — одна задача): **Сделать** → **Вернуть** → **Разблокирует** → **Когда**.
- Владелец закрывает задачу: `[ ]` → `[x]` + дата + короткий итог. Можно ответить в чате — оркестратор перенесёт сюда.
- **Значения секретов сюда не пишутся** — только в `.env` или менеджер паролей.

Статусы: `[ ]` открыта · `[~]` в процессе · `[x]` выполнена · `[-]` снята (с причиной).
